
# 🚦 Road Accident Analysis Dashboard

## 📌 Project Overview

The **Road Accident Analysis Dashboard** is a data-driven visualization project designed to analyze road accident data and uncover critical insights related to accident frequency, severity, location, time, and contributing factors. The dashboard helps stakeholders, policymakers, and researchers understand accident patterns and make informed decisions to improve road safety.


## 🎯 Objectives

* Analyze trends in road accidents over time
* Identify high-risk locations and accident-prone areas
* Understand accident severity and casualty distribution
* Study the impact of time, weather, and road conditions
* Support data-backed road safety planning and policy decisions

---

## 📊 Dashboard Features

* **Total Accidents & Casualties Overview**
* **Accident Trends by Year / Month**
* **Severity-wise Accident Analysis**
* **Location-based Accident Distribution**
* **Time-based Analysis (Day/Night, Peak Hours)**
* **Vehicle Type & Road Condition Impact**
* **Interactive Filters for Dynamic Exploration**


## 🛠 Tools & Technologies Used

* **Power BI** – Dashboard creation and visualization
* **Microsoft Excel / CSV** – Data source and preprocessing
* **Data Cleaning & Transformation** – Power Query
* **DAX** – Calculated measures and KPIs

---

## 📂 Dataset Description

The dataset includes the following key attributes:

* Accident Date & Time
* Location (Area / City / Region)
* Accident Severity
* Number of Casualties
* Vehicle Type
* Road Condition
* Weather Condition

> ⚠️ *The dataset is used only for analytical and educational purposes.*

---

## 🔍 Key Insights

* Peak accident rates occur during **rush hours**
* **Urban areas** record a higher number of accidents
* **Two-wheelers** are involved in a significant portion of accidents
* Poor **road and weather conditions** increase accident severity
